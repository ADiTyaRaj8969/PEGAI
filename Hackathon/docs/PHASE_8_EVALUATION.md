### Why these cases

| Property | Reason |
|---|---|
| 8 topics covered | Shows the system is not tuned to one problem shape |
| Case 10's error at **step 3** | The error is mid-working, so a diagnoser that always answers "1" scores 25%, not 100% |
| Case 9 inverts a fraction | Produces a *plausible* wrong number — harder than an obvious one |
| Case 12 adds times | The classic work-rate misconception; tests whether the hint is genuinely targeted |
| Answers include 120 **twice** (cases 1, 8) | Guards against the guard being tuned to specific values |

> **Build these by hand, not with a model.** A case set generated by the same model being evaluated
> measures agreement with itself, not correctness.

## 8.2 The Harness

```python
# eval/run_eval.py
import json, argparse
from tutor.solver import solve
from tutor.hints import generate_ladder, generate_v1
from tutor.guard import leaks, safe_hint
from tutor.diagnose import diagnose

def eval_v1(case, sol):
    """Baseline: split the raw text into three hints, check L1 and L2."""
    text = generate_v1(case["problem"])
    parts = {}
    for lvl in (1, 2, 3):
        marker = f"Hint {lvl}:"
        if marker in text:
            rest = text.split(marker, 1)[1]
            nxt = f"Hint {lvl + 1}:"
            parts[lvl] = rest.split(nxt)[0].strip() if nxt in rest else rest.strip()
    return [lvl for lvl in (1, 2) if lvl in parts and leaks(parts[lvl], sol).leaked]

def eval_v2(case, sol):
    """Final: hints as actually displayed, i.e. after the guard."""
    lad = generate_ladder(case["problem"], sol)
    out = []
    for lvl in (1, 2):
        shown, _ = safe_hint(lvl, getattr(lad, f"l{lvl}"), sol)
        if leaks(shown, sol).leaked:
            out.append(lvl)
    return out

def main(version):
    cases = json.load(open("eval/cases.json"))
    leaked_cases, step_hits, step_total, rows = 0, 0, 0, []

    for c in cases:
        sol = solve(c["problem"])
        lvls = eval_v1(c, sol) if version == "v1" else eval_v2(c, sol)
        if lvls:
            leaked_cases += 1

        hit = None
        if "wrong_step" in c:
            step_total += 1
            d = diagnose(c["problem"], c["working"], sol)
            hit = (d.first_wrong_step == c["wrong_step"])
            step_hits += bool(hit)

        rows.append({"id": c["id"], "topic": c["topic"],
                     "leaked_levels": lvls, "step_correct": hit})
        print(f"{c['id']:>3}  {c['topic']:<22} leak={lvls or '-':<8} step={hit}")

    print(f"\nLeak Rate @ L1-L2 : {leaked_cases}/{len(cases)} = "
          f"{100 * leaked_cases / len(cases):.1f}%")
    if step_total:
        print(f"Step Localisation : {step_hits}/{step_total} = "
              f"{100 * step_hits / step_total:.1f}%")
    json.dump(rows, open(f"eval/results_{version}.json", "w"), indent=2)

if __name__ == "__main__":
    p = argparse.ArgumentParser()
    p.add_argument("--version", choices=["v1", "v2"], required=True)
    main(p.parse_args().version)
```

### The one subtlety that decides whether the metric is honest

`eval_v2` measures the hint **after** `safe_hint` — what the student actually sees. That is the
right thing to measure, and it is why V2 should score 0%.

But measured that way the number is partly tautological: the guard both produces and judges the
output. So report **both** numbers:

| What to report | How to get it |
|---|---|
| **Leak rate as displayed** | `eval_v2` as written — the honest user-facing figure |
| **Leak rate before the guard** | Call `leaks()` on `lad.l1` / `lad.l2` directly |

The second shows how often the Phase 3 prompt alone would have leaked — which is what proves the
prompt engineering helped, separately from the guard catching it. Expect something like:

```
V1 (one prompt)                    ~33%
V2 before the guard (prompt only)  ~8%     <- the prompting techniques
V2 as displayed (prompt + guard)     0%    <- the guarantee
```

Three numbers tell a far better story than one, and pre-empt the sharpest question a judge can ask.

## 8.5 Demo Rehearsal — 5 minutes

| Time | Beat | Line |
|---|---|---|
| 0:00 | The problem | "Students need help, not answers. Giving the answer early ends the learning." |
| 0:30 | **Unseen input** | Ask a judge for a word problem. Type it live. |
