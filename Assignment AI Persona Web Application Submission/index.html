1 Gemini API key

The key is entered here at runtime and kept only in this browser tab's sessionStorage. It is never written into the source file, so this project can be published to GitHub safely.

Get a free key: aistudio.google.com/app/apikey. “Load my models” asks the API which models your key can actually use and refills the dropdown — useful because model availability differs between accounts and regions.

2 Select persona(s)

Pick one for a single perspective, or several to compare them. Each persona is defined by a six-element Prompt Card — click “View Prompt Card” on any persona to see exactly what is sent.

3 Your question

Ask anything about your career path, skills, studies or placements.

4 Responses

Prompt actually sent to Gemini (single request)
